#  服务端 PostJson API 🚀

一个轻量级、高性能的 Go 语言原生 HTTP API 服务，专门用于处理 JSON 格式的 POST 请求。内置限流、日志分割、优雅关闭等生产级特性。

## 📋 功能特性

- ✅ **JSON API** - 接收和响应 JSON 格式数据
- ✅ **限流保护** - 令牌桶算法，防止恶意请求
- ✅ **日志分割** - 按天自动分割日志文件
- ✅ **优雅关闭** - 等待现有请求处理完再退出
- ✅ **安全中间件** - 安全响应头、跨域支持
- ✅ **配置外置** - YAML 配置文件，便于管理
- ✅ **健康检查** - `/health` 端点监控服务状态

- **计划更新** - 身份认证与访问控制

## 🚀 快速开始

### 前置要求

- Go 1.21 或更高版本
- Git

```bash
# 克隆项目
git clone https://github.com/JIMGAN1/PostJson-api.git

# 进入项目目录
cd PostJson

# 安装依赖
